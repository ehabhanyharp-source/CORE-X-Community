# Roadmap

## 0.2.0 release gates
- [ ] Pass CI on minimum and stable Flutter.
- [ ] Run demo on desktop and capture genuine screenshots.
- [ ] Run `flutter pub publish --dry-run` and resolve issues.
- [ ] Review package name availability and publisher account.
- [ ] Tag an actual tested release and publish, if approved by the maintainer.

## Next candidates (not implemented)
- Column resizing and accessible focus indicators for tables.
- Large dataset benchmarks and pagination adapters.
- Additional reduced-motion transitions and theme tokens.
- Keyboard navigation and screen reader testing on actual desktop platforms.

Priorities should reflect real developer feedback. No usage statistics or performance claims are made without evidence.
